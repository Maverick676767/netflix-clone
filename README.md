# Netflix React Clone — Educational UI Project

A responsive streaming-platform UI built with React, Vite, React Router and Lucide icons.

## Features
- Login and signup demo screens
- Responsive home page with hero banner and horizontal content rows
- Movie and series browsing with genre filtering
- Search by title, genre or description
- Title details page
- Video player interface placeholder
- Persistent My List using browser localStorage
- Mood Mix recommendations
- Responsive desktop, tablet and mobile layouts

## Requirements
- Node.js 18 or newer
- npm

## Run locally
```bash
npm install
npm run dev
```
Open the local URL printed by Vite (usually http://localhost:5173).

## Production build
```bash
npm run build
npm run preview
```

## Important notes
- This is a frontend educational demo. Login/signup is simulated in the browser; it is not secure authentication and does not use a backend.
- The player is a UI placeholder. Add a video source that you own or are licensed to use to enable playback.
- Movie metadata and poster/backdrop URLs are sample content. Replace them with approved assets or a movie API such as TMDB, following its terms and attribution requirements.
- This project is not affiliated with Netflix. Use it for learning and do not present it as the official Netflix service.
